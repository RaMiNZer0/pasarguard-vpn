# 🛡️ افزونه یکپارچه پروتکل‌های VPN پاسارگارد (OpenVPN, IKEv2, L2TP/IPsec)

افزونه رسمی، ماژولار و سبک‌وزن برای اضافه کردن پروتکل‌های VPN بومی به پنل مدیریت **PasarGuard**.  
این سیستم بدون هیچ‌گونه دستکاری در سورس اصلی یا تغییر در ساختار دیتابیس پاسارگارد (Zero Core Mutation) کار می‌کند و با سهمیه‌ها، گروه‌ها و کاربران پنل به صورت ۱۰۰٪ بلادرنگ همگام است.

## 🚀 ویژگی‌ها و قابلیت‌های کلیدی

- **اتصال بومی بدون نرم‌افزار جانبی:**
  - **IKEv2 (strongSwan):** اتصال مستقیم در آیفون، آیپد و مک بدون نیاز به هیچ برنامه‌ای، از طریق پروفایل رسمی `.mobileconfig`.
  - **OpenVPN:** پروتکل پایدار UDP روی پورت ۱۱۹۴ با فایل‌های آماده `.ovpn`.
  - **L2TP/IPsec:** پشتیبانی پیش‌فرض در تمام نسخه‌های ویندوز و اندروید.
- **همگام‌سازی بلادرنگ با دیتابیس پاسارگارد:**
  - هر تغییری در پنل (غیرفعال کردن کاربر، تمدید حجم، تغییر تاریخ انقضا) فوراً در اتصال VPN اعمال می‌شود.
  - کاربران می‌توانند با همان رمزهای عبور فعال خود (Trojan / Hysteria / Shadowsocks) متصل شوند.
- **کیل‌سوئیچ هوشمند و محاسبه حجم (Traffic Accounting):**
  - به محض اتمام حجم کاربر، اتصال او روی تمام سرورها در کسری از ثانیه قطع (Terminate) می‌شود.
- **مصرف بهینه منابع:**
  - کمتر از ۱۵ مگابایت رم، ۰٪ پردازنده در حالت آماده‌باش (Idle).
- **مقاومت در برابر قطعی (Failsafe & Circuit Breaker):**
  - در صورت ریستارت پنل مستر یا قطعی موقت اینترنت بین سرورها، اتصال کاربران روی نودها قطع نمی‌شود.

## 🌐 معماری سیستم: روی کدام سرورها باید نصب شود؟

| ساختار شما | سرور پنل مستر (Master) | سرورهای نود (Worker Nodes خارج) |
|---|---|---|
| **تک‌سرور (Single Server)** | ✅ **فقط همین سرور** نصب می‌شود | نیازی نیست |
| **چندسرور (Multi-Node)** | ✅ دستور حالت **مستر** اجرا می‌شود | ✅ دستور با فلگ **`--node`** روی هر سرور خارج اجرا می‌شود |

```text
[کاربران آیفون / ویندوز] 
         │ (OpenVPN / IKEv2)
         ▼
┌──────────────────────────────┐       ┌──────────────────────────────┐
│   سرور نود ۱ (آلمان)         │       │   سرور نود ۲ (ترکیه)         │
│   Node Worker + Hooks        │       │   Node Worker + Hooks        │
└──────────────┬───────────────┘       └──────────────┬───────────────┘
               │                                      │
               │ (احراز هویت و کسر ترافیک امن REST API) │
               ▼                                      ▼
┌─────────────────────────────────────────────────────────────────────┐
│                       سرور پنل اصلی پاسارگارد                        │
│          داشبورد وب + دیتابیس + موتور همگام‌ساز بلادرنگ             │
└─────────────────────────────────────────────────────────────────────┘
```

## 🛠️ راهنمای گام‌به‌گام نصب

### حالت ۱: نصب روی تک‌سرور (Single Server)
اگر پنل پاسارگارد و لوکیشن سرور شما هر دو روی یک سرور قرار دارند، ترمینال لینوکس را باز کرده و این دستور را وارد کنید:

```bash
sudo bash <(curl -fsSL https://raw.githubusercontent.com/RaMiNZer0/pasarguard-vpn/main/install.sh)
```

سپس پاسارگارد را ریستارت کنید:
```bash
# اگر پاسارگارد با داکر اجرا می‌شود:
docker restart pasarguard

# یا اگر به صورت سرویس سیستمد است:
sudo systemctl restart pasarguard
```

---

### حالت ۲: نصب توزیع‌شده (Multi-Node Cluster)

#### مرحله اول: روی سرور پنل اصلی (Master Panel)
دستور نصب پنل مستر را اجرا کنید:
```bash
sudo bash <(curl -fsSL https://raw.githubusercontent.com/RaMiNZer0/pasarguard-vpn/main/install.sh)
docker restart pasarguard
```

#### مرحله دوم: روی سرورهای نود خارج (Worker Nodes)
روی هر سرور خارج (نود آلمان، ترکیه، هلند و ...):

۱. دستور نصب سایدکار نود را اجرا کنید:
```bash
sudo bash <(curl -fsSL https://raw.githubusercontent.com/RaMiNZer0/pasarguard-vpn/main/install.sh) --node
```

۲. متغیرهای اتصال به سرور اصلی را در فایل محیطی نود تنظیم کنید:
```bash
# تنظیم آدرس پنل مستر و کلید امنیتی ارتباط
export PASARGUARD_MASTER_URL="https://panel.yourdomain.com"
export PASARGUARD_NODE_API_KEY="توکن_امنیتی_شما"
export PASARGUARD_NODE_NAME="DE-Hetzner1"
```
*(می‌توانید این متغیرها را در `/etc/environment` ذخیره کنید تا بعد از ریبوت هم پایدار بمانند).*

## 🔐 تنظیمات پیشرفته و امنیت

یک فایل نمونه با نام [`config.env.example`](config.env.example) در ریپازیتوری قرار دارد:

```env
# ۱. دیتابیس پاسارگارد
PASARGUARD_DB_URL=sqlite:////opt/pasarguard/data/db.sqlite3

# ۲. دامنه مجاز پنل برای CORS امن
PASARGUARD_PANEL_ORIGIN=https://panel.yourdomain.com

# ۳. کلید امنیتی اختصاصی برای تبادل اطلاعات نودها با مستر
PASARGUARD_NODE_API_KEY=your_secret_random_64_char_token

# ۴. رمز پیش‌فرض اتصالات L2TP/IPsec
VPN_L2TP_PSK=your_strong_ipsec_preshared_key
```

برای تولید گواهی‌های معتبر رمزنگاری OpenVPN و IKEv2 با استاندارد RSA 4096-bit:
```bash
sudo bash /opt/pasarguard-vpn/certs/generate_ca.sh
```

## 📱 نحوه استفاده کاربران

1. مدیر وارد پنل پاسارگارد می‌شود.
2. گزینه **`🛡️ مدیریت پروتکل‌های VPN`** در سایدبار یا دکمه شناور گوشه پایین صفحه را باز می‌کند.
3. در تب **دانلود کانفیگ کلاینت‌ها**:
   - نام کاربری را انتخاب یا تایپ می‌کند.
   - فایل `.ovpn` تک‌فایلی آماده اتصال برای کلاینت OpenVPN تولید می‌شود.
   - برای کاربران اپل (iOS/macOS)، فایل پروفایل `.mobileconfig` دانلود می‌شود که با یک کلیک بدون نیاز به نرم‌افزار، VPN را در تنظیمات گوشی نصب می‌کند.

## 🗑️ حذف کامل افزونه (Uninstaller)

اگر به هر دلیلی خواستید افزونه را به طور کامل پاک کنید، با اجرای یک دستور تمام سرویس‌ها، پچ‌های داشبورد و فایل‌های افزونه بدون کوچک‌ترین آسیبی به پاسارگارد و دیتابیس آن پاکسازی می‌شوند:

```bash
sudo bash <(curl -fsSL https://raw.githubusercontent.com/RaMiNZer0/pasarguard-vpn/main/uninstall.sh)
docker restart pasarguard
```
